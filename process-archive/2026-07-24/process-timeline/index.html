2026.07.24 / Key visual redesign

断絶を、
実装へつなぐ。

見た目の新しさから始めず、企業の意思とAI時代の実装力の間にあるギャップを、01C-Cの接続と状態変化へ翻訳した。選んだ表現だけでなく、外した情報と別セクションへ移した表現も残す。

01 / Foundationブランド基盤

07.24 / Purpose

AIの可能性ではなく、企業の意思を起点にする

BeforeAIで可能性を広げ、企業変革へ伴走する会社
→
After企業の意思に、AI時代の実装力を与える会社

理由: 作れることと顧客へ正しく届けられることの間には、要件化、レビュー、品質保証、導入のギャップがある。Hashigodakaの価値は、その断絶を専門知識と実装責任で埋めることにあるため。

Foundation
07.24 / Boundary

支援の完了条件を一つへ固定しない

Before顧客の自走化または事業成果までを一律の責任範囲にする
→
After顧客が意思を決め、Hashigodakaは合意した成果に必要な実装へ責任を持つ

理由: 開発代行なら仕様と品質、活用支援なら実利用と定着までというように、支援形態で責任範囲は変わる。顧客の事業判断まで代行する会社として見せないため。

02 / Typography書体の確定

07.24 / D-I

D-Iを正式な書体方向にする

BeforeD-I（Sora × LINE Seed JP）とH-J（Geologica × M PLUS 1）を全ページで比較
→
AfterD-I（Sora × LINE Seed JP）へ確定

理由: 実ページ全体で組版を比較し、ブランドの力強さ、明快さ、和欧文の釣り合いをD-Iで固定する判断に至ったため。

Selected D-I

03 / Direction主役の再設定

07.24 / 00

写真を外し、01C-Cそのものを主役にする

Before人物写真や多数の窓で、AIによる実装の広がりを見せる
→
After画面いっぱいの01C-Cで、断絶がつながる状態を見せる

理由: ブランドとして最も伝えたいのは生成量ではなく、企業の意思と実装のギャップを正しく接続する役割だから。

07.24 / 01

01C-CをZ軸方向へ倒し、状態変化を流す

Before正面向きの単色モチーフを静的に置く
→
AfterZ軸方向へ倒した大判モチーフを、左から右へ無色からブランドカラーへ変える

理由: 正本のシルエットを主役に保ちながら、意思が実装へ接続されていく時間を一つの方向性で表せるため。

04 / FinalistsEとG

07.24 / E-G

異なる質感を持つEとGへ絞る

Beforeベタ面、ノイズ、粒子、強弱の異なる拡散境界を比較
→
AfterEは粒子の定着、Gは拡散した境界の色づきとして残す

理由: Eは断片が形になる過程、Gは断絶の境界がなじむ過程を、それぞれ異なる触感で表せるため。

Finalists E / G
07.24 / Light

追従光を面の再描画から分離する

Beforeマウス移動ごとに大きな面を再描画し、ちらつきと位置ずれが発生
→
After画面座標に独立した白い拡散光をE/Gへ共通適用

理由: モチーフのアニメーションとライトを別レイヤーにし、輪郭の硬さ、位置ずれ、広いちらつきを抑えるため。

07.24 / Header

HeaderをHeroの一部としてなじませる

BeforeHeaderへHeroと同色の面を付け、下枠で分離
→
After透明なHeaderをHeroへ重ね、下枠を削除

理由: 画面上端までキービジュアルを連続させ、色面を二重に説明しないため。

07.24 / Copy

メッセージの補助情報と白い面を外す

Before見出し背面の白い塗り、英字ラベル、補足コピーを併記
→
After主メッセージとCTAだけを背景へ直接置く

理由: 01C-Cの状態変化と主メッセージの二つへ視線を絞り、説明の帯を重ねないため。

07.24 / Scale

EのモチーフをG相当まで拡大する

BeforeEだけ画面占有率が小さく、粒子の密度が局所的
→
AfterEを約1.27倍に拡大し、Gと同等の主役面積にする

理由: 質感だけを比較できるよう、モチーフの存在感を候補間で揃えるため。

05 / Motionコピー演出

07.24 / E1-E3

E3の静かなフォーカスインを採用

Beforeせり上がり＋ぼけ、横マスク、静かなフォーカスインを比較
→
After粒子定着後、メッセージとCTAを移動を抑えて静かに表示

理由: 粒子側に十分な情報量があり、文字まで細かく動かすと主役が競合する。定着の完了を受けて内容だけが明瞭になる流れが最も自然なため。

Selected E3

06 / Page rhythm次セクションとの関係

07.24 / Height

次見出しを覗かせず、Heroを100svhへ戻す

BeforeHeroを画面高より96〜140px短くし、次のService見出しを表示
→
AfterHeroを100svhに戻し、キービジュアルを一画面で完結

理由: 次セクションの予告より、01C-Cとコピーの没入感を優先するため。

07.24 / Concept

Gの背景表現をOur Conceptへ移す

BeforeGの拡散境界をHeroの最終候補として保持
→
AfterHeroはE方向で進め、Gの背景アイデアは次のOur Conceptで活用を検討

理由: 良い表現を捨てず、キービジュアルと同じ役割を競わせない。会社の考えを説明する次セクションで、境界がなじむ表現を意味と結び直すため。
