# コーポレートサイト再設計プロセス・アーカイブ（2026-07-22〜23）

## このアーカイブの目的

2026-07-22に開始し、翌23日まで継続したコーポレートサイト再設計セッションの比較画面と判断を、
後から検証できる一次資料として保存する。完成画面だけでなく、ホームページ全体の方向、ファースト
ビュー、サービスのイラストと構成、チーム、Newsへ段階的に収束した過程を含む。

比較画面は当時の一時HTMLの最終状態を保存したもので、各ラウンド内で上書きされたすべての中間状態を
復元するものではない。細かな変更順と理由は [`process-timeline/`](process-timeline/) と各案件リポジトリの
設計文書・Git履歴を併せて確認する。

## このセッションで確定したページ構成

Hero → Service → Team → News → Contact → Footer。

- Heroは01C-Cを写真の大きな窓として使い、2行のメッセージだけを主役にする。
- Serviceは3事業を個別カードで説明し、写真ではなく人物イラストを使う。
- Teamは写真とモーダルを使わず、4名のプロフィール全文を一覧で見せる。
- NewsはTeamの後へ置き、Surface色の01C-Cを下端から立ち上げ、中央の負形へ1件の記事を通す。
- Recruit、共創プロセス、会社概要の独立セクションは表示しない。

## 資産と公開範囲

- 比較画像はこのセッションで生成した検討用画像、またはHashigodakaのサイト資産から構成する。
- 参考にした第三者サイトのスクリーンショット、画面録画、ロゴは収録しない。
- 参考URLは設計文書の判断根拠として保持するが、外部サイトの造形をHashigodakaの資産として扱わない。
- サービス俯瞰図の比較HTMLが参照していたローカル開発サーバー上の画像は、同一内容の自社資産を
  `assets/`へ複製し、アーカイブ単体で閲覧できる相対参照へ変更した。
- Google Fontsへの外部参照を含む比較HTMLがある。表示環境で読み込めない場合はシステムフォントへ
  フォールバックする。
- Imagegen画像内の文字や細部は完成条件ではない。採用案はデザイントークンと正本SVGを使って
  HTML/CSSへ再構築する。

## 参照例の扱い

構成やスクロール体験の観察に、公開されている企業サイト、イラストライブラリ、映像作品を参照した。
提供元とURLは案件の設計記録に残し、画像・録画自体はこのアーカイブへ転載していない。公開可否は
リンク先の公開ページを参照する範囲に限り、第三者資産の再配布権は主張しない。

## 保存範囲の制約

- 各比較UIは「比較用・実装外」であり、本番サイトのナビゲーションや操作ではない。
- 00〜11は一時プレビューに残っていた最終スナップショットで、会話中に上書きされたピクセル状態は
  推測で復元していない。
- タイポグラフィのD-I / H-Jはこの時点では未決定で、本番プレビュー上の切り替えUIも暫定である。
- NewsのJで採用した外周クロップは、そのセクション境界に限定した例外であり、01C-Cの一般的な
  利用ルールを無条件に緩和するものではない。
