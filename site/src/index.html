デザイン原則

主役を一つに絞る

写真、図形、大見出しのうち、最も伝えたいものを一つだけ主役に選び、余白で視線の順序をつくります。

色に役割を与える

白に近い面を基盤にし、鮮やかな色は意味のある箇所へ集中させます。複数の色には、主役と補助の関係をつくります。

関係と責任を描く

顧客の意思と、ハシゴダカが担う実装の責任を具体的に示し、合意した成果へ進む関係として表現します。

新しさを価値で語る

技術の新しさそのものではなく、人や事業にもたらす変化、実現した成果、品質を支える方法を伝えます。

プロジェクト設計

カードや小セクションの見出し。本文の強調だけを目的に使わない。

Heading 4.hsg-type-heading-4

背景の用途

小区分やカード内部の下位見出し。Heading 3の配下で使い、本文の強調には使わない。

Body Large.hsg-type-body-large

事業の構想と実装の間に入り、実際に使われる仕組みを一緒につくります。

ページ冒頭のリード文。本文より大きく、見出しより静かに導入する。

Body.hsg-type-body

目的を共有し、必要な機能を整理し、設計から開発までを一つの流れとして進めます。読みやすさを優先し、一行を長くしすぎません。

標準本文。和文は一行35〜45字程度を目安にし、長文では段落を分ける。

Body Small.hsg-type-body-small

対象範囲や前提条件など、本文を補う説明に使用します。

補足説明。重要情報を小さく押し込む目的では使わない。

お問い合わせ種別

入力項目名や意味のある分類名。装飾的な英大文字や等幅書体に置き換えない。

Label Large.hsg-type-label-large

プロジェクトを相談する

ボタンと主要リンク。動作が予測できる具体的な動詞を使う。

日付、出典、画像注釈などのメタデータ。本文に必要な情報は入れない。

Code.hsg-type-code

var(--hsg-color-brand-primary)

コード、変数名、ファイル名など、コードとして読む識別子だけに使う。

運用ルール

階層は意味で選ぶ見た目を小さくしたいという理由だけで、見出しレベルを飛ばさない。

本文幅を制御する標準本文は和文35〜45字程度を目安にし、読み返しやすい行長を保つ。

強調を重ねない太字、色、大きさを同時に重ねず、情報の優先度に必要な一手だけを使う。

等幅はコードだけ小見出し、状態、日付を技術的に見せる装飾として等幅書体を使わない。

レイアウト

4px基準の余白と、画面幅に応じた4・8・12列グリッドで、強い表現を整った構造で支えます。

Spacing scale

余白の共通尺度

迷ったときは隣接する要素間の関係が伝わる、最小の値を選びます。

Page gutter

Mobile / Tablet / Desktop。画面端から本文や主要要素までの最低余白です。

Content width

Reading / Standard / Wide。文章、通常ページ、広いビジュアルの最大幅を分けます。

Section space

Small / Medium / Large。セクションの重要度と情報量に応じて使い分けます。

Responsive grid

Mobile · 4
Tablet · 8
Desktop · 12

尺度から選ぶ個別の都合で中間値を増やさず、定義済みの余白スケールを使う

幅に上限を設ける画面が広くても文章と操作要素を無制限に引き伸ばさない

構造変化で切り替えるブレークポイントは機種名ではなく、内容が窮屈になる地点で使う

一つの主役写真、図形、見出しを同時に競わせず、余白で優先度を示す

ロゴ

選定書体を土台にしたワードマークを、正式なブランド資産として提供します。

Hashigodaka ワードマーク

採用済み

Sora Boldの現行組みをアウトライン化した正式ワードマークです。サイトヘッダーや資料のロゴ枠で使用できます。

  • 単色、縦横比固定で使う
  • 既定色はText Primary。暗い面ではText Inverseへ反転する
  • 変形、回転、色分解、字形の改変をしない
  • ブランドモチーフとの固定ロックアップは未定義
SVGを開く

写真とモチーフ

人間味と精密さを、役割の異なる二つの表現で支えます。

人物・実景

働く人、顧客との関係、成果へ責任を持つ主体を見せます。雰囲気だけのストック写真は避けます。

固有モチーフ

写真がない場面ではAI画像を既定にせず、Hashigodaka固有の抽象モチーフを使用します。

ブランドモチーフ

採用済み

厚い左右の面で力強さを、中央の接続でH・橋渡し・共創を、上下のくびれで蝶とバタフライエフェクトを表します。

  • 単色、縦横比固定で使う
  • 既定色はPrimary。モノクロ時はText Primary、暗い面ではText Inverseへ反転する
  • 回転、反転、切り取り、左右別色への分解をしない
  • 32px未満では使わない。正式ロゴ、ファビコン、固定ロックアップとして直接使わない
