# Hashigodaka Design System

Hashigodakaのデザイン原則、デザイントークン、ブランド資産、コンポーネント、
AI向け配布物の正本です。

人間が判断に使えるデザインガイドと、AIエージェントが成果物の生成・検証に使える
機械可読な定義を、同じ根拠から提供します。

## 現在のフェーズ

ビジュアルの方向性を定める準備段階です。最初に4象限のムードボードをローカルHTMLで
比較し、選定した方向をデザイン原則とトークンへ変換します。

現在の目的、決定事項、未決事項は [docs/design-brief.md](docs/design-brief.md) を参照してください。
