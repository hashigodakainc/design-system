# ビジュアル参照例

代表がHashigodakaのビジュアルイメージに近い候補として提示したサイトを、2026-07-16に
デスクトップ表示で観察した記録。各サイトを模倣するのではなく、共通する判断原則と、
Hashigodakaへ転用する要素を抽出するために使う。

サイトのスクリーンショットや画像の掲載権は未確認である。このリポジトリと記事には画像を転載せず、
参照URLと観察結果だけを記録する。記事で画像が必要になった場合は、掲載許諾を確認するか、
原則を反映した自作の比較図へ置き換える。

## SPIKE STUDIO

- URL: <https://spikestudio.jp/>
- 4象限上の位置: **幾何学的・精密 × 大胆・表現的**

### 観察できる特徴

- 黒と黄・金を中心にした高いコントラスト。
- 大きなサンセリフ体、黒い矩形へ載せた見出し、非対称な構図。
- 稲妻状の図形、粒子、金属的な質感をページ全体の主役にする。
- 下層も大きな図形と文字を使い、ブランドの勢いを継続する。

### 借りられる要素

- 一目で記憶に残る固有のグラフィックモチーフ。
- 大きな見出しと明確なコントラスト。
- 大胆な表現を、ナビゲーションと情報階層で制御する構造。

### そのまま持ち込まない要素

- 金属光沢、粒子、稲妻、AIを前面に出した未来的演出の組み合わせ。
- ページ全体を高い声量で統一すること。
- 技術力を、派手さやAIらしさだけで表現すること。

## HQ

- URL: <https://corp.hq-hq.co.jp/>
- 4象限上の位置: **幾何学的・精密 × 静か・抑制的**

### 観察できる特徴

- 白を中心に、濃紺と淡い青紫を少量使う。
- 大きなサンセリフ体と広い余白で、主張を静かに見せる。
- 線と粒子による抽象グラフィックが、技術性と柔らかさを両立する。
- 角丸のナビゲーションと薄い影により、精密さを冷たくしすぎない。

### 借りられる要素

- 白地、濃色の文字、限定したアクセント色による静かな基盤。
- 大きなタイポグラフィと余白による明快な階層。
- 技術を端末画面やコードではなく、抽象的な構造として見せる方法。

### そのまま持ち込まない要素

- 淡いグラデーションと粒子だけで先進性を表すこと。
- 一般的なSaaS・HRテック企業と区別しにくい柔らかさ。
- 角丸や影を装飾として増やし、精密さを弱めること。

## MIZUKARA

- URL: <https://mizukara.com/>
- 4象限上の位置: **有機的・親密 × 静か・抑制的**
- 補足: 写真の大きさには強い表現性があるが、色と組版は抑制されている。

### 観察できる特徴

- 画面の大部分を占める人物写真を、一つの明確な主役にする。
- 白と黒を中心に、色数を抑える。
- 対面する人物、縦組みのコピー、広い余白による編集的な構成。
- 人物の存在感は強いが、装飾を重ねず静けさを保つ。

### 借りられる要素

- 技術の背後にいる人間と責任を、質の高い写真で伝えること。
- 一つの主役へ視線を集中させる編集的な構図。
- 白黒を基盤にしても、冷たくならない人間的な温度。

### そのまま持ち込まない要素

- 人物写真だけでブランドの価値を説明すること。
- コーチング、ライフスタイル、美容分野に見える語り口や写真演出。
- 人間味を優先するあまり、開発組織としての構造と精密さを弱めること。

## 3サイトから見える共通点

- テンプレート的なコーポレートサイトではなく、固有の視覚的な主役がある。
- 大きなタイポグラフィと明確な情報階層を使う。
- ベースの色数を絞り、主役へ注意を集める。
- 余白と整った組版が、強いグラフィックや写真を支えている。
- 技術、社会、人間のいずれか一つを、抽象語ではなく視覚的に具体化している。

## Hashigodakaで検証する組み合わせ

- **基盤:** HQの静かな余白、情報階層、抽象的な構造表現。
- **人間的な温度:** MIZUKARAの人物への焦点と、編集的な写真の使い方。
- **記憶に残る一手:** SPIKE STUDIOの強い主役。ただし、AIらしい金属光沢や粒子ではなく、
  Hashigodakaの責任、構造、品質を意味する固有モチーフへ置き換える。

目標は3サイトの折衷ではない。静かな基盤、人物の温度、固有の主役という役割を分け、
Hashigodaka固有の一つの視覚言語として再構成する。
