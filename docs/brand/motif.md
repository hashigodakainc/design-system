# 固有モチーフ

## 現在の候補

01C-Cを、写真がない場面で検証利用できるHashigodaka固有モチーフの主案とする。
正式ロゴではなく、曲線、小サイズ、ワードマーク横組みの検証前にある候補資産である。

![01C-C](../../assets/motifs/01c-c.svg)

## 形が担う意味

- 左右の厚い面と矩形に近い外周は、実装を担う力強さと単体マークとしての安定を表す。
- 中央を横断する青い接続は、Hの横画、橋渡し、共創を兼ねる。
- 上下の曲線的なくびれは、蝶と、小さな意志が大きな変化へ波及するバタフライエフェクトを示唆する。
- 外側を直線的に、内側だけを有機的にすることで、H-Jの太い文字骨格と人間味を両立する。

## 利用ルール

- 一つの面では原則として一つだけ使い、写真や別の大きな抽象図形と主役を競わせない。
- 単色で使う。既定はPrimary `#00A0FF`、モノクロ要件ではInk、暗い面への反転ではCanvasを使う。
- 縦横比を固定して拡大縮小する。回転、反転、輪郭線化、左右別色への分解はしない。外周の切り取りも
  原則として行わず、採用済みのサイト固有例外だけを下記の条件で許容する。
- 32px未満は未検証のため使用しない。小さく使う場合は中央の青い接続と上下の負形を実機で確認する。
- 正式ロゴ、ファビコン、アプリアイコン、ワードマークとの固定ロックアップにはまだ使わない。

- SVG資産：[`assets/motifs/01c-c.svg`](../../assets/motifs/01c-c.svg)

SVGは単体ではPrimaryで表示される。HTMLへインライン展開した場合は`color`で単色を差し替えられる。
形状の`path`を複製して編集せず、正本のSVGを参照する。

## 採用済みのサイト固有例外

- Team導入では、Primary単色の全形を大きく拡大し、画面左端とセクション下端で切る。切断面を
  コンテンツカラム内へ残さず、右のプロフィール領域へ侵入させない。
- Newsでは、Surface単色の全形を幅146vwまで拡大し、左右を画面外、下端をContactとの境界で切る。
  中央の負形を記事情報の通り道として残し、見出しや記事より高いコントラストにしない。
- どちらも、正本SVGの縦横比、向き、pathを維持したCSSマスクまたは元SVG参照で実装する。これらの
  例外を、他の面で任意に切り取ってよい一般ルールへ拡張しない。

## 確定前に検証すること

- 24px、32px、48pxで中央の接続と負形が潰れないか。
- H-Jワードマークの左へ置いたとき、面積、間隔、光学重心が釣り合うか。
- B2B LPと図解で反復しても、蝶やHの説明が強すぎず、構造と勢いを作れるか。
