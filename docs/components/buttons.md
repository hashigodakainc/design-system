# Buttons

ボタンは、ブランドカラーではなくニュートラルカラーの面積と輪郭によって、行動の重要度を
3段階で示す。Primary / Secondaryという名称はブランドのPrimary / Secondary Colorとは
別の概念であり、コンポーネント内の優先順位を表す。

## Primary

- 用途：画面内で最も優先する行動。原則として一つのまとまりに一つまで。
- 通常：Inkの背景、Canvasの文字、背景と同色の枠線。
- Hover：黒のトーンを`#35313A`へ変え、白文字を保つ。
- 例：問い合わせを送信する、申し込みを確定する。

## Secondary

- 用途：Primaryに次ぐ行動。Primaryと並置しても同じ強さに見せない。
- 通常：Canvasの背景、Inkの文字、Neutral Borderの枠線。
- Hover：Inkの背景とCanvasの文字へ反転する。
- 例：詳細を見る、別の方法を選ぶ。

## Tertiary

- 用途：補助的な行動や、現在の流れから戻る操作。
- 通常：透明背景、Inkの文字、Inkの下線。ボックス形状を作らない。
- Hover：背景を付けず、文字と下線をMutedへ変える。
- 例：戻る、後で行う、補足情報を開く。

## 共通仕様

- ラベルはActionのタイポグラフィを使い、操作後の結果が予測できる具体的な動詞を選ぶ。
- キーボードフォーカスは3pxのInkアウトラインと3pxのオフセットで示す。
- 色だけで階層や状態を伝えず、面・枠線・下線の形状差も保つ。
- `prefers-reduced-motion: reduce`では色のトランジションを無効にする。
- 実装クラスは`styles/components.css`の`.hsg-button`と、階層別の修飾クラスを使う。
