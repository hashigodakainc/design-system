# Hashigodaka デザインガイドライン

Hashigodakaのデザインに関する横断的な判断のうち、トークンや資産メタデータを補完する定性的な
ルールを記載する。対象は、成果物の構図、情報階層、意味、伝え方とする。

## ブランド表現の規則

デザイン・写真・図解・コピーでは次を守る。

### 顧客との関係の見せ方

- 顧客を、変えたい現実と届けたい価値を持ち、意思決定を担う当事者として描く。
- ハシゴダカは、顧客が決めた方向を正しく実装し、合意した成果への到達を担う存在として描く。
- 「伴走」は、顧客とハシゴダカがそれぞれの責任を果たし、合意した成果へ進む関係として表す。
- 支援の結末は、顧客と合意した事業成果への到達を基準に描く。自走化は、顧客が望む場合の
  選択肢として扱う。

### コピー

中心に置く言葉は、意思、実装、届ける、責任、変化、判断、循環、現場。

コピーでは、内容に応じて次の観点を具体的に伝える。

- AIの導入から事業や現場の変化へ至る、判断、実装、品質保証の過程
- 顧客が定めた方向と、ハシゴダカが担う実装・提供の責任
- 提供できる価値、その実現条件、品質を支える方法
- 新しい技術が人や事業にもたらす具体的な価値
- 新しさや先進性を裏付ける、実現した成果、活用方法、品質上の価値

## 色と面

- 白に近い基盤面を最も広く取り、鮮やかな色は意味のある箇所へ集中させる。
- ブランドカラーを複数使う場合は、面積差を付け、意味のある主役と補助の関係を明確にする。
- 状態やデータ系列は、色に加えて、ラベル、アイコン、形、線種などを併用し、複数の手掛かりで
  識別できるようにする。

## レイアウト

- 写真、図形、大見出しのうち一つを主役に選び、余白で視線の順序を作る。

## 固有モチーフ

- ブランドモチーフは、左右の面と中央の接続が示す、橋渡し、共創、変化の象徴として扱う。
