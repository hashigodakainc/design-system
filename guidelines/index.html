デザイン原則

見た目を揃えるだけでなく、判断を揃える。

力強く、明快に

大きなタイポグラフィと一つの強い主役で、伝えるべきことを記憶に残します。

余白に責任を持つ

白に近い面を広く取り、鮮やかな色は図解やブランド表現など意味のある場所へ絞ります。

人を置き去りにしない

丸い装飾ではなく、働く人、顧客との関係、成果への責任から人間味を表します。

仕組みまで実装する

一度きりの表現で終わらせず、再利用できるトークン、部品、判断基準へ落とします。

新しい技術を開放する

新しい技術を一部の専門家の中に閉じず、人や事業が使える形にして開放します。

事業の構想と実装の間に入り、実際に使われる仕組みを一緒につくります。

Body.hsg-type-body

目的を共有し、必要な機能を整理し、設計から開発までを一つの流れとして進めます。読みやすさを優先し、一行を長くしすぎません。

標準本文。和文は一行35〜45字程度を目安にし、長文では段落を分ける。

コード、変数名、ファイル名など、コードとして読む識別子だけに使う。

運用ルール

階層は意味で選ぶ見た目を小さくしたいという理由だけで、見出しレベルを飛ばさない。

本文幅を制御する標準本文は和文35〜45字程度を目安にし、読み返しやすい行長を保つ。

強調を重ねない太字、色、大きさを同時に重ねず、情報の優先度に必要な一手だけを使う。

等幅はコードだけ小見出し、状態、日付を技術的に見せる装飾として等幅書体を使わない。

レイアウト

4px基準の余白と、画面幅に応じた4・8・12列グリッドで、強い表現を整った構造で支えます。

Spacing scale

余白の共通尺度

迷ったときは隣接する要素間の関係が伝わる、最小の値を選びます。

Page gutter

Mobile / Tablet / Desktop。画面端から本文や主要要素までの最低余白です。

Content width

Reading / Standard / Wide。文章、通常ページ、広いビジュアルの最大幅を分けます。

Section space

Small / Medium / Large。セクションの重要度と情報量に応じて使い分けます。

Responsive grid

Mobile · 4
Tablet · 8
Desktop · 12

尺度から選ぶ個別の都合で中間値を増やさず、定義済みの余白スケールを使う

幅に上限を設ける画面が広くても文章と操作要素を無制限に引き伸ばさない

構造変化で切り替えるブレークポイントは機種名ではなく、内容が窮屈になる地点で使う

一つの主役写真、図形、見出しを同時に競わせず、余白で優先度を示す

ロゴ

選定書体を土台にしたワードマークを、正式なブランド資産として提供します。

Hashigodaka ワードマーク

採用済み

Sora Boldの現行組みをアウトライン化した正式ワードマークです。サイトヘッダーや資料のロゴ枠で使用できます。

  • 単色、縦横比固定で使う
  • 既定色はInk。暗い面ではCanvasへ反転する
  • 変形、回転、色分解、字形の改変をしない
  • ブランドモチーフとの固定ロックアップは未定義
SVGを開く

写真とモチーフ

人間味と精密さを、役割の異なる二つの表現で支えます。

人物・実景

働く人、顧客との関係、成果へ責任を持つ主体を見せます。雰囲気だけのストック写真は避けます。

固有モチーフ

写真がない場面ではAI画像を既定にせず、Hashigodaka固有の抽象モチーフを使用します。

ブランドモチーフ

採用済み

厚い左右の面で力強さを、中央の接続でH・橋渡し・共創を、上下のくびれで蝶とバタフライエフェクトを表します。

  • 単色、縦横比固定で使う
  • 既定色はPrimary。モノクロ時はInk、暗い面ではCanvasへ反転する
  • 回転、反転、切り取り、左右別色への分解をしない
  • 32px未満では使わない。正式ロゴ、ファビコン、固定ロックアップとしては使わない

Badges

NeutralPrimarySecondaryVioletOrange

色付きバッジは白文字を使い、コントラストを満たす専用トーンで表示します。状態の意味はSemantic Colors策定後に割り当てます。

Primary重要度：高

黒背景と白文字。画面内で最も優先する行動に使います。

Secondary重要度：中

白背景、黒文字、グレー枠。ホバー時は黒背景へ反転します。

Tertiary重要度：低

透明背景、黒文字、黒下線。面を作らず補助的な行動を示します。

ボタンの3階層と基本状態、バッジの表示仕様は採用済みです。ボタン寸法のバリエーション、無効・処理中状態、アイコン併用は今後追加します。
